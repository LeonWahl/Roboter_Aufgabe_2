## Was macht der online_line_finder

Der online_line_finder ist der aus dem Übungsblatt 4 gebaute Code, dabei wurde dieser mit der Funktion erweitert, das dieser zusätzlich bescheid sagen kann, ob eine tür offen oder zu ist.

## Aktevierung

```bash
ros2 run online_line_finder online_line_finder
```

Diese kann bei bedarf auch in der launch file akteviert werden, da es eine zusätzliche Aufgabe ist, die nicht verlangt wurde aber funktioniert
